# synent-task6-CustomerSegmentation-Krina

[Problem Statement]:

The objective of this project is to segment customers into distinct groups based on their purchasing behavior and demographic characteristics. Customer segmentation helps businesses better understand their customers, develop targeted marketing strategies, and improve customer engagement.

[Dataset Details]:

The project uses the Mall Customer Dataset, which contains information about customers visiting a shopping mall.
Features
Customer ID
Gender
Age
Annual Income (k$)
Spending Score (1–100)
The dataset provides valuable information for identifying customer groups with similar characteristics and spending patterns.

[Approach]:
The project was implemented using Python, Pandas, Matplotlib, Seaborn, and Scikit-learn.

Key steps included:

Loading and exploring the dataset.
Performing data preprocessing and feature selection.
Visualizing customer attributes to understand patterns and distributions.
Applying the K-Means Clustering algorithm to group customers based on income and spending behavior.
Using the Elbow Method to determine the optimal number of clusters.
Visualizing the resulting customer segments using scatter plots.
Interpreting each cluster to understand customer behavior.


[Results]:

The K-Means model successfully grouped customers into distinct segments based on their annual income and spending scores.

Key insights include:

High-income customers with high spending behavior.
High-income customers with low spending behavior.
Moderate-income customers with average spending habits.
Low-income customers with varying spending patterns.
Clearly defined customer groups that can support targeted marketing and business strategies.

Overall, the project demonstrates how clustering techniques can be used to identify meaningful customer segments and improve decision-making through data-driven marketing.
